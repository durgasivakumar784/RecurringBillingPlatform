# Recurring Payment, Subscription Management and Billing Automation Platform

## Project Overview

This project is a subscription-based billing automation platform developed using FastAPI and PostgreSQL.

The system manages customer subscriptions, automated billing cycles, invoice generation, payment tracking, usage-based charges, and revenue analytics.

---

## Technology Stack

Backend:
- Python
- FastAPI

Database:
- PostgreSQL

ORM:
- SQLAlchemy

API Documentation:
- Swagger UI

---

## Features

### 1. Plan Management
- Create subscription plans
- Manage pricing details
- Monthly billing support

### 2. Customer Management
- Add customers
- Maintain customer information

### 3. Subscription Lifecycle

Supports:

- Trial
- Active
- Past Due
- Cancelled

### 4. Automated Billing

Features:

- Invoice generation
- Usage charge calculation
- Final billing amount calculation

### 5. Payment Management

Supports:

- Payment records
- Payment status tracking
- Failed payment handling

### 6. Usage Based Billing

Tracks:

- Usage type
- Quantity
- Unit price
- Additional charges

### 7. MRR Analytics

Provides:

- Active subscription count
- Monthly recurring revenue calculation

### 8. Audit Logging

Tracks:

- Subscription actions
- Invoice activities
- Payment events
